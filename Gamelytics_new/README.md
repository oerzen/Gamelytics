# 移动游戏用户增长与行为洞察分析（Gamelytics_new）

> 重构后的全链路移动游戏运营分析：单一 Notebook 打通「用户增长 → 留存 → 商业化 → 玩家画像 → 流失预测 → 实时监控」完整链路。

## 项目简介

本子项目是 Gamelytics 题目的**重构版**，将旧版分散在多个 Notebook 的分析整合为一条标准化链路。基于 100 万注册玩家、960 万登录记录与 40.5 万 A/B 测试用户，系统回答留存、商业化、画像与运营三大业务问题，并配套完整的数据目录与 20 张可视化图表。

## 结果结论

- **留存**：首月留存 15.4%~18.9%，早期流失率 79.4%，注册后前 5 天为关键干预窗口。
- **商业化**：测试组促销方案 ARPPU 提升 **12.75%**（p<0.001），综合效应量评分判定测试组胜出。
- **画像**：消费-留存呈倒 U 型，低消费层最活跃、高消费鲸鱼登录最少；K-Means/DBSCAN/GMM 交叉验证行为聚类。
- **预测与运营**：RF/XGBoost 识别高风险玩家，动态风险评分构建绿/黄/橙/红四级监控预警系统。
